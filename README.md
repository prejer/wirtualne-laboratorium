# Wirtualne Laboratorium Fizyczne

Zadania doświadczalne Olimpiady Fizycznej w 3D — gotowy układ, prawdziwa fizyka, własne pomiary.

- Strona: `index.html` (statyczna, bez zależności).
- Silnik: `engine.js` budowany z `src/core/*.js` poleceniem `python3 build.py`.
- Jak dodać zadanie: `src/ZADANIA.md`, szablon: `zadania/_szablon.js`.
